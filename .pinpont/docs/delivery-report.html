验证结果

自动化测试

5 个测试模块共 99 个用例，全部通过：annotations（16）、render（34）、check（9）、export（13）、server（27）。

端到端 smoke test

真实启动服务后验证完整闭环：render 渲染 → daemon 启动 → 注解 + 直接编辑 → save-all 写盘 → check 收件箱 → export 回环 → 服务复用 → shutdown。全部通过。

smoke test 抓到并修复的三个真实缺陷

  1. Windows 编辑器写入的 UTF-8 BOM 导致首行标题识别失败——所有读取统一改为 utf-8-sig
  2. export 列表条目间被错误插入空行——列表改为单块拼接
  3. CJK 审计链路验证（实为 PowerShell 客户端编码问题，Python 客户端确认服务端正确）

跨平台保障

pathlib 全覆盖、Windows ctypes 进程存活检测、popen 分离含 Job Object breakaway、UTF-8 stdio reconfigure、WSL 浏览器派发。Windows 与 macOS 均可运行。

已知边界

  1. 含内联标记（粗体、链接）的段落不能直接编辑，需走注解信道——防止拍平行内格式
  2. html 入口的消毒不做完整 HTML5 错误恢复，重度畸形标记可能嵌套异常
  3. 图片 v1 支持整图批注，区域框批注留待 v2
